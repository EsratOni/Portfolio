# Esrat Sultana — Portfolio

Static site, no build step. Files:
- `index.html` (the whole site: styles and scripts included)
- `hero/sketch.svg` and `hero/final.svg` (the hero's wireframe-to-final cursor reveal)
- `Esrat_Sultana_CV.pdf` (linked from "Download CV")

## Put it live on Vercel
1. Create a GitHub repository named `portfolio` and upload everything in this folder, keeping the `hero` folder.
2. On vercel.com, sign in with GitHub, then Add New → Project → Import `portfolio` → Deploy (no settings to change).
3. Rename the address under Settings → Domains, for example `esrat-sultana.vercel.app`.

## Updating
- New CV: replace `Esrat_Sultana_CV.pdf`, same file name.
- Clinic study results: edit the "Outpatient clinic experience" card text in `index.html`.
- The contact form opens the visitor's email app addressed to esratsultana25@gmail.com.
